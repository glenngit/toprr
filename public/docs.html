Documentation and API

toprr fetches the daily Top 10 from your streaming services and requests genuinely new titles via Radarr / Sonarr (Seerr optional). Configure everything in the GUI; the HTTP API below is for automation and scripts.

Getting started

In the GUI: set your Streaming Availability key in Settings, pick country and services on the Dashboard, then Check for new titles and submit.

Authentication

Every endpoint (except auth) needs a session cookie or an API key sent as X-Api-Key. Generate a key under Settings → Account & API access.

Running a sync

POST /api/sync with {"submit":false} for a dry run, or {"submit":true} to request. Browser calls also send X-Requested-With: toprr.
